Minified scripts, styles, fonts and animated icons served through jsDelivr.

- No third-party scripts, no trackers, no `eval`
- Every file is versioned and served with a sha384 integrity hash
- Fast on mobile; respects reduced-motion and dark mode

## Free public tools

Free, lightweight scripts and styles for any website — Blogger, WordPress, React,
Next.js, Webflow, Shopify, Wix, Ghost or plain HTML. Table of contents, copy-code
buttons, cookie consent, offline notice, dark mode, read-later bookmarks, QR code
generator, WhatsApp tools, 179 animated icons, SEO JSON-LD, ad-blocker notice and
Blogger topic/chapter helpers.

**Docs, live demos and the QR / WhatsApp link APIs:** https://risewithvj.github.io/vjkit/

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/risewithvj/vjkit@1/public/css/vj-toc.min.css">
<script defer src="https://cdn.jsdelivr.net/gh/risewithvj/vjkit@1/public/js/vj-toc.min.js"></script>
```

`@1` always gives the newest 1.x release. Use an exact version such as `@1.0.0` to freeze it.
