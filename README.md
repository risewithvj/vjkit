# vjkit

**Front-end assets for [VL Tech Official](https://vltechofficialblog.blogspot.com)**

Designed and developed by **Vijaya Kumar L (RisewithVJ)**

[Website](https://vltechofficialblog.blogspot.com) · [LinkedIn](https://www.linkedin.com/in/vijayakumarl/)

</div>

---

Protected builds of the scripts, styles, fonts and animated icons used by
VL Tech Official. Files are minified and served through jsDelivr.

- No third-party scripts, no trackers, no `eval`
- Every file is versioned and served with a sha384 integrity hash
- Fast to load on mobile; respects reduced-motion and dark mode
