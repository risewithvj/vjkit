# Security

- No file in this repo loads code from any third-party host.
- No file sends data anywhere. Cookies are first-party only (`vj_consent`).
- Always load files from a version tag (for example `@v0.1.0`), never `@main`, and include the `integrity` hash from `sri.json`.
- Report a problem by opening a GitHub issue, or message Vijaya Kumar L on LinkedIn: https://www.linkedin.com/in/vijayakumarl/
