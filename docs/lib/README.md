# vjkit public

Free, lightweight scripts and styles for any website: Blogger, WordPress, React, Next.js, Webflow, Shopify, Wix, Ghost or plain HTML.
Designed and developed by **Vijaya Kumar L (RisewithVJ)**.

**Docs, live demos and tutorials:** https://risewithvj.github.io/vjkit/

## How to load

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/risewithvj/vjkit@1/public/css/vj-toc.min.css">
<script defer src="https://cdn.jsdelivr.net/gh/risewithvj/vjkit@1/public/js/vj-toc.min.js"></script>
```

`@1` always gives the newest 1.x release (safe updates). Use an exact version such as `@1.0.0` to freeze it.

## What is included

| File | What it does |
|---|---|
| `js/vj-toc` + `css/vj-toc` | Table of contents from your headings. Styles: box, sidebar, float, numbered, progress |
| `js/vj-copy` + `css/vj-copy` | Copy button on code blocks. Styles: corner, label, icon, bar |
| `js/vj-cookie` + `css/vj-cookie` | Cookie consent with Google Consent Mode v2. Styles: bar, card, modal, minimal, choices |
| `js/vj-offline` + `css/vj-offline` | Offline / back-online notice. Styles: toast, bar, pill, full |
| `js/vj-theme` + `css/vj-theme` | Dark mode, colour themes, back-to-top with progress ring |
| `js/vj-bookmarks` + `css/vj-bookmarks` | Read later list saved in the visitor's browser |
| `js/vj-qr` + `css/vj-qr` | QR code generator: widget, auto QR and JavaScript API |
| `js/vj-wa` + `css/vj-wa` | WhatsApp: message tool, click-to-chat links, floating button |
| `js/vj-icons` + `css/vj-icons` | 179 line icons with 13 animations |
| `js/vj-seo` | Automatic JSON-LD: BlogPosting, Breadcrumb, FAQ |
| `js/vj-adblock` + `css/vj-adblock` | Polite ad-blocker notice. Styles: banner, card, modal |
| `blogger/vj-topics`, `blogger/vj-chapters` + `blogger/vj-blogger.css` | Blogger only: topic cards, previous/next in a series |
| `js/vj-all` + `css/vj-all` | One file with toc, copy, offline, theme, bookmarks and icons |
| `fonts/` | Inter, Space Grotesk, JetBrains Mono (third-party, SIL OFL 1.1) |
