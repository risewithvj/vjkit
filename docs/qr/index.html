Use it as a link (QR API)

Make a QR from any app, email or button by building a link:

https://risewithvj.github.io/vjkit/qr/?text=YOUR_TEXT&size=400&dark=0a1931&light=ffffff&level=M&download=png

text = the link or text (URL-encoded) · size 100–2000 · dark/light = hex colours without # · level L/M/Q/H · download=png or svg (optional).
