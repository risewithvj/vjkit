Get started on your platform

  1. Blogger → Theme → Edit HTML.
  2. Paste the <link> lines just before </head> and the <script> lines just before </body>.
  3. Save. For a single post, you can also paste them in the post's HTML view.

Tip: in the theme, write & as &amp; inside attribute values.

  1. Easiest: install a header/footer plugin (for example "WPCode") and paste the lines into Header and Footer.
  2. Or in a block theme: Appearance → Editor, add a Custom HTML block where you need a widget such as <div data-vj-qr-tool></div>.
  3. Developers: wp_enqueue_script('vj-toc', 'https://cdn.jsdelivr.net/gh/risewithvj/vjkit@1/public/js/vj-toc.min.js', [], null, true);
// Load once (for example in app/layout.tsx or index.html)
import Script from 'next/script';
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/risewithvj/vjkit@1/public/css/vj-toc.min.css" />
<Script src="https://cdn.jsdelivr.net/gh/risewithvj/vjkit@1/public/js/vj-toc.min.js" strategy="afterInteractive" />

// In a component, after your content renders:
useEffect(() => { window.VJToc?.init(); window.VJI?.render(); window.VJQR?.init(); }, [content]);

// Or use the APIs directly:
const svg = window.VJQR.svg('https://example.com', { level: 'M' });
const chat = window.VJWA.link('919876543210', 'Hi!');

Paste the <link> in <head> and the <script defer> before </body>. That's all. Webflow, Shopify, Wix, Ghost, Hugo and Jekyll all have a "custom code" or "code injection" box for this.
